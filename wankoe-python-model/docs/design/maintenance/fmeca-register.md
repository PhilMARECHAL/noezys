## The client's 5 choices (2026-08-15)

1. SCOPE = the FULL equipment park: the 35 electrical_loads consumers of data/default_parameters.json as the equipment nomenclature + the process machines' engine sheets; diverters (DV.GF, sliver) and silos added as non-electrical in-scope items.
2. CRITICALITY = RPN = S x O x D, each scored 1-10 (RPN 1-1000); action thresholds >= 200 CRITICAL / 100-199 WATCH.
3. SEVERITY anchor MIXED: 9-10 safety/environment; 6-8 full line stop; production severity set from ENGINE knowledge (single points high, redundant lower, quality-critical screens mid-high).
4. OCCURRENCE = generic reliability classes by equipment type [H], MODULATED by engine load factors (docs/design/maintenance/fmeca-engine-evidence.json).
5. DELIVERABLE = this data-first register (.json) + .md printout + preventive-maintenance-plan.md sorted by RPN + dated decision-log row + CLAUDE.md pointer.

## Method

**Criticality = RPN = S x O x D**, each scored 1-10 (RPN 1-1000).
**Thresholds: RPN >= 200 = CRITICAL** (5 modes), **100-199 = WATCH**
(71 modes), **< 100 = BASE** (71 modes). 38 equipment items,
147 failure modes scored.

### Severity S (mixed anchor — client choice 3)

| S | Meaning |
|---|---|
| 10 | catastrophic safety potential (fire/explosion, fatality potential) |
| 9 | major safety/environment event (reportable emission, fire) |
| 8 | single-point failure stopping a whole production chain, repair > 1 week |
| 7 | single-point chain stop, repair 1-7 days — or quality breach on a FIRM commitment with thin margin |
| 6 | full chain stop < 1 day, or quality nonconformity reaching a committed product |
| 5 | partial capacity loss / quality deviation caught before shipment |
| 4 | redundancy or stockpile absorbs; reduced rate |
| 3 | local function loss, buffers absorb |
| 1-2 | negligible / cosmetic |

### Occurrence O (generic class [H], engine-modulated — client choice 4)

| O | Order of frequency (at ACTUAL annual running hours) |
|---|---|
| 1-2 | < 1 per 10-20 y |
| 3-4 | 1 per 3-10 y |
| 5-6 | 1 per 1-3 y |
| 7-8 | several per year to monthly |
| 9-10 | weekly to continuous |

Modulation rule: generic class per equipment type [H], then +1 per ~90-120 % engine load factor, +2 above ~115 % or engine-certain duty exceedance; -1 where annual hours are far below continuous-plant baseline.
Every base class is a hypothesis **[H]** — the line is under construction,
no site failure history exists yet; classes to be recalibrated on CMMS data.

### Detection D

| D | Meaning |
|---|---|
| 1-2 | instrumented alarm/trip in place |
| 3-4 | caught by routine rounds or existing monitoring |
| 5-6 | found only by scheduled inspection/measurement (PSD, vibration route, thermography) |
| 7-8 | hidden (internal, teardown/NDT, hidden protective function) |
| 9-10 | no realistic detection before failure |
