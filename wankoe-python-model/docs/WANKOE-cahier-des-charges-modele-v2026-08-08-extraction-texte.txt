Préambule
Ce document spécifie le modèle de calcul déterministe de la ligne WANKOE (zones 1.1, 1.2, 1.3), destiné aux développeurs Python. Il suit exactement la structure de cahier des charges d'entrée définie avec l'équipe de programmation, en neuf chapitres.
Nature du modèle
Flowsheet STATIQUE DÉTERMINISTE des trois zones : pour un jeu de paramètres (un « scénario ») et une base de temps au choix, il calcule la « photo » synchronisée de toute la ligne — flux, granulométries, bilan matière et eau, dimensionnement des machines, écarts aux objectifs et aux plafonds de marché.
Aucune dynamique, aucun aléa. Chaque exécution = un scénario. L'utilisateur définit chaque scénario et compare les photos ; le moteur n'optimise pas seul et n'IMPOSE aucun choix d'exploitation (météo, mode, réglage, objectif).
Structure fixe (fidèle aux schémas de principe en blocs), avec blocs et modes activables par paramètre on/off. Interface web ; module d'auto-calibration sur mesures.
Trois règles d'or
Chaque symbole d'une formule est défini (nom, unité). Un symbole non défini est renvoyé sous forme de question, jamais deviné.
Un abaque ou une courbe constructeur est fourni en tableau de valeurs, avec le mode d'interpolation (linéaire ou log).
Les données d'entrée sont SÉPARÉES du code : tout paramètre est modifiable sans reprogrammation.
Frontière paramètres / codé en dur
Codé en dur (moteur) : lois physiques et identités mathématiques — conservation masse et eau, concassage (Rosin-Rammler), loi de Bond, partition de crible (Karra), logique de circuit fermé, séchage ; grille de mailles unique ; STRUCTURE des blocs.
Paramètres (libres) : granulo mesurée, humidités, saisons/météo, modes, réglages machines, plafonds de marché, objectifs, coefficients de calibration, capacités installées, heures/disponibilité.
Critères d'acceptation
Bouclage masse + eau automatique à chaque scénario (tolérance stricte).
Reproduction des cas de référence documentés (chapitre 9).
Tests automatisés + cas de référence livrés avec le code.

1.3  Convention de courbe
Courbe granulométrique = % PASSANT CUMULÉ à chaque maille.
Représentation : mailles en log, passant linéaire 0–100 %.
1.4  Humidité et matière
Humidité en BASE HUMIDE : 8 % = 8 kg d'eau / 100 kg de matière humide.
Grandeur conservée = SOLIDE SEC ; l'eau est un flux séparé, retirée uniquement au séchoir.
Bilan bouclé : solides secs entrée = sortie ; eau entrée = eau des produits humides + vapeur.

3.  Fiche par machine
Les modèles de calcul communs (§ 3.0) portent le détail des formules et la définition de chaque symbole. Chaque fiche machine (§ 3.1 et suivants) renvoie au modèle utilisé et fournit ses paramètres. Les coefficients marqués [H] sont des valeurs par défaut issues de la littérature, à confirmer par essai (paramètres tunables, non codés en dur).
3.0  Modèles de calcul communs

xc = x80 / (ln 5)^(1/n)
P(x) = 1 − exp( −(x / xc)^n )      (passant cumulé du produit)
Le produit est tronqué au-dessus de 1,7·x80 (masse réétalée) ; la fraction du flux plus fine que x80 passe inchangée.

4.  Schéma de procédé (flowsheet)
Enchaînement des machines par zone, flux étiquetés. Les transferts (convoyeurs, élévateurs, vis) ne sont pas repris (sans influence procédé).
4.1  Zone 1.1 — concassage / criblage primaire
Tout-venant → grille (grizzly 80 mm) : passant <80 mm contourne ; refus +80 mm → CR.5003.
CR.5003 + passant grizzly → CR.5009 → crible SR.5007 (avec retour percuteur).
SR.5007 (35/20) : refus +35 → CR.5011 → retour crible (boucle fermée).
Coupe 20-35 : MODE 1A → KFS ; MODE 1B → retour CR.5011 (pas de KFS).
Passant 0-20 → stockpile → zone 1.2.
4.2  Zone 1.2 — reprise / AgLime
Stockpile 0-20 → BF.5101 → SR.5105 (15/5) : tranches +15, 5-15, 0-5.
MODE 2A : 5-15 → FeedLime ; +15 et 0-5 → circuit fermé.  MODE 2B (pluie) : tout → FeedLime.  MODE 2C : tout → circuit fermé.
Circuit fermé : SR.5115 (1,7 mm) ; refus +1,7 → CR.5107 → retour. Passant 0-1,7 = AgLime.
AgLime (humide) = produit ; FeedLime → stockpile → zone 1.3.
4.3  Zone 1.3 — séchage / grits / UltraFin
Stockpile FeedLime → DY.03 (séchoir) : humidité → 0,5 %. Eau retirée = vapeur (seule sortie d'eau).
Produit séché → SN.21 (4/2/1,5) : tranche 2-4 = grits (produit direct).
Refus +4 et sliver 1,5-2 → ML.26 → retour SN.21 (boucle fermée).
Passant 0-1,5 = FeedLime fines → SP.36 (coupe ~100 µm) → CL.38 → UltraFin ; refus grossier reste FeedLime fines.

8.  Critère d'optimisation
Le moteur n'optimise pas automatiquement : l'utilisateur définit chaque scénario et compare les photos. Règle d'arbitrage : atteindre les objectifs fermes (KFS, grits) en minimisant l'excédent invendable — en priorité les fines calcaires, principal risque de la ligne.
