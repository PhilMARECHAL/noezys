## 1. Scope of supply

One (1) impact crusher (HAZEMAG AP-S 1010 reference class) closing the
zone-1.1 0/20 loop (20/40 recycle re-crushing). Complete with hydraulic
apron adjustment for routine CSS changeover, blow-bar sets (2 full spare
sets — mandatory priced line), bearing temperature + vibration
monitoring provision, rotor balancing acceptance provision (trim
weights or weight-matched bar sets), commissioning supervision
(mandatory priced line).

## 3. Witnessed tests

1. **Capacity test at the 1B point**: 90 t/h wet sustained 2 h at
   CSS 18 / v 30 — no rotor stall, product P80 consistent with 17.7 mm.
2. **Mode-changeover demonstration** CSS 30 → 18 → 30 within the stated
   time.
3. **Gradation acceptance** at CSS 30 / v 30 within table tolerance;
   downstream tie-in = 0/20 spec (loop closure at 20 mm).
4. **Balance acceptance**: vibration below the vendor grade after a
   witnessed bar change.
5. Absorbed-power check (engine references 21.5 kW 1A / 42.5 kW 1B).

## 5. Machine-specific clauses

- THE decisive item: a WRITTEN capacity guarantee at CSS 18 / v 30 on
  wet limestone — the auto-mode-1B planning rule depends on it; an
  offer without it is non-conforming.
- Bar metallurgy specified for limestone WITH tramp risk (crack-tolerant
  backing); the zone-1.1 metal detector + overband (RFQ 01 perimeter)
  protects this machine — vendor states its max tolerable tramp.
- Motor 132 kW per the reference class; worst absorbed 42.5 kW —
  amply confirmed, no uprate requested.
- Vendor states its breakage-parameter basis for power/gradation
  guarantees (A = 60 / b = 0.80 [H] pending drop-weight tests — none
  launched, client decision 2026-08-16).
