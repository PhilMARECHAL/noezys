## 1. The frame set by the client's ten decisions

| # | Decision (client 2026-08-16) | Consequence in this dossier |
|---|---|---|
| Q1 | **Contractual product curve** | Offers are ranked on the guaranteed curve (20/35 preservation + fines < 20 mm cap at the 60 mm setting), witnessed gradation test mandatory |
| Q2 | Quarry guarantees **max lump ≤ 250 mm** | Design lump = 250 mm; machines with a 250 mm feed window are fully eligible (Komatsu re-enters); guarantee goes into the quarry-works spec |
| Q3 | **Sizer class** | Toothed double-roll candidates drop out (Gundlach S-Series, Luoyang Dahua 2PGC); "sizer geometry" confirmation is an RFQ gate for blurred Chinese designations |
| Q4 | Abrasivity data exist (client supplies) | Wear-life guarantees priced against the data — attached to the RFQ |
| Q5 | Truck → hopper → apron feeder → machine, **outdoor** | Weather execution specified; sizer moisture tolerance is a ranking plus |
| Q6 | **Vendor standard twin-drive** (2 × ~110 kW class) | No minimum-drive engineering; restart under load by design; soft starters |
| Q7 | **Critical spares kit** in the initial order | Segments set + shaft = mandatory priced line of every offer |
| Q8 | RFQ to **premium brands, West + China** (emphasis China) | One specification, identical witnessed tests for every bidder — that is what makes offers comparable across continents |
| Q9 | Greenfield civil | No dimensional envelope constraint; vendors optimize feed height/discharge |
| Q10 | **Metal detector + overband magnet** upstream | Detection threshold agreed with the selected vendor; protects machine AND downstream |

## 4. What every bidder must return (the comparability core)

1. **Guaranteed product curve** at the 60 mm setting on WANKOE limestone
   (wet, 7–12 % moisture): % < 20 mm (cap) and 20/35 mm yield — the
   PRIMARY ranking criterion (Q1). Witnessed gradation test at the
   maker's works on client material, value table + declared interpolation
   (golden rule 2/3).
2. Confirmed frame/roll length at 250 t/h wet, max lump 250 mm (Q2), and
   the standard twin-drive package with soft starters + restart-under-load
   torque verification (Q6).
3. Tooth profile + segment metallurgy for soft porous WET limestone,
   scraper/comb arrangement — wear-life guarantee priced against the
   client abrasivity data (Q4, data to be attached).
4. Critical spares kit: one segments set + one shaft, priced, with lead
   times (Q7); Europe/Africa after-sales terms (commissioning, response
   time).
5. Outdoor execution (Q5): IP-rated drives, sealing, lubrication range,
   guards/CE for export.
6. Sizer-geometry confirmation (inward-rotating twin shafts, through-flow,
   segment teeth) — mandatory for the Chinese designations whose
   nomenclature straddles classes (Q3 gate).
7. Interface data for the upstream metal detector/overband threshold (Q10)
   and hopper/apron-feeder handshake (Q5).

## 5. Honesty section — documentation asymmetry

- No Chinese maker in the field publishes product-gradation curves, per-frame
  drive powers, or duty-specific selection charts the way MMD/thyssenkrupp/
  Komatsu do. Every Chinese candidate carries at least one missing datum
  (power: EXCT, Zhenyuan, CITIC; curve: all five). The Q1 contractual-curve
  requirement is precisely what neutralizes this asymmetry at offer stage —
  the witnessed test speaks one language.
- Reference bias: CITIC HIC and Zhenyuan are effectively coal-referenced;
  only Tianhe shows limestone lines (pages intermittently unreachable
  through the proxy — the RFQ demands the contactable limestone reference
  list).
- Swept and dropped, with reasons: NHI (no sizer line documented), SANME
  (no sizer at all), Luoyang Dahua (2PGC toothed double-roll = the excluded
  class), Tangshan Shenzhou (coal separation, no sizer OEM), Beijing HOT
  (integrator, no own catalog), XCMG/Sany (no sizers), Shandong Laiwu
  (listing exists, no verifiable model specs). Several proxy failures
  (403/503) mean some absences are "not retrievable", not proven
  "non-existent".
- All designations verified against maker or dealer pages 2026-08-16;
  catalog figures are assistant-compiled from vendor documents, not engine
  output.
