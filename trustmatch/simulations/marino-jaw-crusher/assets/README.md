# Photos du parcours Marino × TrustMatch × Zenith

Ce dossier accueille les 5 photos générées (MidJourney / Flux / autre) qui illustrent
le parcours commercial de Marino, responsable de maintenance chez Carmeuse Moha,
depuis le devis allemand trop cher jusqu'à l'exploitation du concasseur Zenith.

## Format recommandé

- **Ratio** : 16:9
- **Résolution minimale** : 1920×1080 (idéal 2400×1350)
- **Compression** : JPEG qualité 85-90 (poids 200-500 ko/photo)
- **Bonus optionnel** : `00-hero.jpg` en 21:9 pour bannière

## Comment uploader depuis iPhone

1. Ouvrir https://github.com/PhilMARECHAL/noezys sur Safari iPhone
2. Basculer sur la branche `claude/new-project-setup-lDXa6`
3. Naviguer dans `trustmatch/simulations/marino-jaw-crusher/assets/`
4. Bouton **« Add file » → « Upload files »**
5. Sélectionner les 5 photos depuis l'app Photos
6. Renommer si besoin (`01-marino-inquiet.jpg`, etc.)
7. **Commit directly to** `claude/new-project-setup-lDXa6`
