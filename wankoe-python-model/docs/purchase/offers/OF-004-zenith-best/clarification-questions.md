Dear Sirs,

Thank you for your quotation dated August 21st, 2026. Before we can
proceed with the evaluation, please clarify the following points,
answering each question by its number.

## A — Decisive technical points

**Q1. Discharge setting range (the key question).** Your specification
sheet states "discharge opening set 40–800 mm" for the 2PG-1216CT.
Our duty requires the discharge setting to be continuously adjustable
within **20–60 mm**, operating point around 60 mm. Please confirm in
writing that the machine offered is delivered configured for the
20–60 mm setting range at our duty (limestone, feed 0–300 mm,
250 t/h), or state the true achievable setting range of the offered
configuration.

**Q2. Product size guarantee as a curve, not a single point.** "0–100 mm"
is a single point. Please provide the **expected product size
distribution table** (cumulative % passing at 10 / 20 / 31.5 / 40 /
50 / 63 / 80 / 100 mm minimum) for the 2PG-1216CT at a 60 mm setting
on limestone feed 0–300 mm, and state whether you will make this
gradation contractual at ±tolerance.

**Q3. Screen apertures.** Your sheet gives the S5X2760-2 mesh range as
2–70 mm but does not state the supplied decks. Please confirm the
screen is delivered with **top deck 35 mm / bottom deck 20 mm**
apertures, state the panel type (woven wire / rubber / PU) and the
aperture manufacturing tolerance, and quote a spare set of both decks.

**Q4. Screen efficiency.** Please state the guaranteed screening
efficiency (or imperfection) for each deck at 250 t/h feed, and the
capacity derating you apply for wet, sticky feed (rain season:
moisture up to ~12 %). Is the machine's stroke/speed adjustable on
site to compensate?

**Q5. Motors.** Confirm motor make/frame for both machines (you state
Siemens), rated power (2×180 kW / 30 kW), voltage/frequency for South
Africa (400 V / 50 Hz — please confirm suitability), IP rating and
insulation class.

## B — Drawings and loads (required for our civil engineering)

**Q6. General-arrangement (mechanical) drawings.** Please supply
dimensioned GA drawings for BOTH machines as offered: 2PG-1216CT
(including motor and speed-reducer footprint, feed inlet and discharge
flange positions) and S5X2760-2 (including feed box, discharge lips,
spring supports). PDF accepted; DWG/DXF appreciated.

**Q7. Static and dynamic loads.** For each machine, please provide the
foundation load diagram: number and position of support points, static
load per point, dynamic/working load per point, and maximum transient
load (start-up / shut-down for the screen; crushing surge for the
roller crusher). For the screen, state the residual dynamic force
transmitted to the structure at operating speed.

**Q8. Foundation and installation drawings.** Anchor-bolt plan (size,
grade, embedment), recommended concrete class, grouting requirements,
and minimum clearances for maintenance (roll extraction, screen media
replacement). You supplied this level of documentation for the
S5X2760-3 and CI5X1315 in June — we need the same for the two machines
actually offered.

**Q9. Weights for transport.** Confirm the shipping weight and the
heaviest single lift for each machine (you state 33 t and 10.085 t
total), the number/size of containers or breakbulk packages, and
whether the rolls/screen box ship assembled.

## C — Tests and guarantees

**Q10. Witnessed performance test.** We require a witnessed test as a
condition of acceptance: 2-hour continuous run at duty (crusher:
250 t/h limestone at 60 mm setting with gradation sampling; screen:
250 t/h feed with efficiency sampling per deck). Please confirm you
accept a factory witnessed test before shipment AND a site performance
test on our material, and state any cost.

**Q11. Wear parts and abrasivity basis.** Our limestone carries ~5 %
embedded quartz. Please state the guaranteed service life (hours) of
the roller teeth/segments and screen media on this basis, the material
grades offered, and price a 2-year wear-parts package for both
machines (your June quotation priced spares — this one does not).

**Q12. Commissioning.** Please quote a fixed-price supervision package
(erection supervision + commissioning + operator training), instead of
the per-diem-only basis, stating the number of days included.

## D — Commercial

**Q13. Payment terms.** Your terms (30 % down, balance before shipment)
place 100 % of the price before any performance is demonstrated. Our
contract frame requires a retention (target: 20 %) payable after the
passed site performance test, with the balance at documented
milestones. Please state the payment structure you can accept.

**Q14. Validity and firmness.** Confirm the USD prices are firm (no
escalation) for the 45-day validity, and state the validity extension
you can grant if our evaluation requires it.

**Q15. Scope boundary.** Confirm exactly what is excluded besides the
diesel generator set and cables (e.g. electric control cabinet, local
isolators, chutes, supporting steel structure), so we can price the
balance of plant without surprises.
